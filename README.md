## Python Fundamentals Assignment

**Track:** Artificial Intelligence & Machine Learning  
**Module:** Week 1 — Python Basics & Problem Solving

## Project 1: Number Guessing Game

This is a console-based game in which the computer selects a random number between 1 and 100. The player gets seven valid attempts to guess the number. The game provides hints, validates input, displays remaining attempts, and offers a play-again option.

**Python concepts:** Variables, conditions, loops, functions, random module, and exception handling.

**Run the project:**

```bash
python task1_number_guessing/number_guessing.py
```

## Project 2: Student Grade & Attendance Tracker

This program collects a student's name, roll number, and marks for three subjects. It calculates the average, assigns a letter grade, calculates attendance, and checks whether the student meets the 75% attendance requirement.

**Python concepts:** Lists, dictionaries, functions, loops, conditions, calculations, and input validation.

**Run the project:**

```bash
python task2_student_tracker/student_tracker.py
```
